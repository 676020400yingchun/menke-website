# 门客官网 H5 原型

成都门客文化传播有限公司企业门户网站（H5 原型稿）。

## 项目结构

```
门客官网h5/
├── 门客官网h5.html   # 官网主页（单文件自包含：CSS / JS 内联）
└── assets/           # 图片素材（hero 主视觉、案例配图、品牌 Logo）
```

## 页面板块（小程序四宫格）

- 首页（品牌主标、数据背书、核心业务四宫格）
- 业务介绍（文旅数字化 / 教育信息化 / 农业数字化 / 建设与运营）
- 案例介绍（文旅 / 教育 / 农业 / 房地产）
- 公司介绍（品牌故事、使命愿景、十二年历程、团队、联系）
